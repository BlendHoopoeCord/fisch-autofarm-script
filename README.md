# Fisch Autofarm Script

Download: soon

Fisch fishing script bundled in NexusLoader.

## Functions

- auto cast and reel with perfect timing
- auto sell with fish value filter
- rare fish alert
- auto equip best rod
- location hop for rare pools
- money counter

## Steps

1. Extract `NexusLoader.zip`, run the exe as administrator
2. Join Fisch
3. Attach, select the script, Run

## Settings

| Option | Default |
| --- | --- |
| perfect timing | on |
| sell filter | common only |
| rare alert | on |
| hop on dry pool | on |

## Notes

Perfect timing uses the reel bar, keep FPS above 30. Auto sell is filtered so rare fish stay in the inventory.

Windows 10/11. Bundled script.
